# Showing the keys

Show people which keys exist, which work right now, and what they can press next.

Shortcuts nobody knows about don't get used. Because your whole keyboard is written in one place, `useStatus` can tell you every Action, its keys written for display, and whether it works where the user is now.

That is enough for [a help sheet that lists what works](use-keys/whole-keyboard/showing-the-keys/a-help-sheet-lists-what-works), greying out the rest. While a Sequence is under way, you can show [every way to finish it](use-keys/whole-keyboard/showing-the-keys/a-hint-after-the-first-key) after the first key.

`useRun` runs an Action by its id, so [a command palette runs an Action by name](use-keys/whole-keyboard/showing-the-keys/a-command-palette-runs-actions), exactly as its keys would.
