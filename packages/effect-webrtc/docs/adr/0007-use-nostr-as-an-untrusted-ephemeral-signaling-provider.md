# Use Nostr as an untrusted ephemeral Signaling Provider

The Nostr provider publishes versioned plaintext negotiation envelopes as signed kind `25050` ephemeral events to every configured relay, addressed by one provider-wide namespace and the recipient's application-defined Peer Identifier. Each Signaling Connection uses a disposable keypair that authenticates the Nostr event but does not prove ownership or uniqueness of its Peer Identifier. Opening succeeds when one relay connects, sending succeeds when one relay acknowledges, incoming events are merged and deduplicated by event identifier, and malformed or stale events become diagnostics rather than terminating signaling; this preserves the core's unreliable-provider model without adding presence, durable delivery, encryption, or a name registry.
