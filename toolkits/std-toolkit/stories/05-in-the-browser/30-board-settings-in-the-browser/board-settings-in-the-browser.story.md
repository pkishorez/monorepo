The board has a settings record: a theme and a page size, one copy for everyone. The browser needs to show it and let someone flip the theme. A collection in the browser needs an id for every row, and the settings from chapter 12 have none, so for now a record with no id is modeled as one row with a fixed key: the settings get a `settingsId` that is always `board`. This chapter brings that one row to the screen and writes a change back.
