`@kestack/connect/browser` runs Connect in a browser tab, for an App's fake mode: `inTab` gives `CloudClient`, Connect Cloud's real handlers over tables (memory unless given a driver) behind the Sign-in fake's Guard, and `Tunnels`; each online computer of `Computers` sends its Heartbeat as `ke-connect` does, and its code Plugin, the real Engine and handlers over the computer's edges, starts on its first socket. `tunnelClients` is `CodeClients` over those tunnels, answered as `ke-connect`'s server answers (`KEY_EXPIRED`, `PLUGIN_MISMATCH`). `CodeClients.dialing` opens each socket with a given dial. The code Plugin's handlers move to `serve/handlers/`, which imports nothing of Node.
