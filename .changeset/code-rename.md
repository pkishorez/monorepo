The app is now `code`: the package, its folder (`apps/code`), its local address (`code.kishore.computer`), its tab titles and the name beside its mark. On a screen wider than 1624px it floats as a centred window whether Vim Mode is on or off, so a reload no longer draws the full screen and then shrinks it. The new address is a new origin to the browser, so Vim Mode starts off there once: turn it on again with Mod+Alt+V.
