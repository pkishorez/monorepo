The Log is now the History, and the Runtime runs one. `History.make(actor, { input })`, `History.load(actor, saved)` and `History.restored(actor, snapshot, at)` make one; it replays itself to any entry (`seek`, `snapshotAt`, `outcome`), moves its Head (`moveHead`, not while a Runtime runs on it), and saves as `{ entries, head }`. `Runtime.start(historyOrActor, layer)` takes the app's Layer instead of reading it from the context, gives back `history`, `snapshot`, `running`, `send`, `start`, `stop` and `workers`, and always starts at the Head's Time; `show`, `drawn`, `clear`, `state` and `log` are gone from it. `Log`, `RuntimeState`, `Replay.make` and `Replay.restored` are removed. In React, `AppOptions.saved` is a saved History, `useRuntime()` returns `{ history, branch, head, running, shown, show, start, stop, clear, workers, frame }`, and showing a Step is the App's own. Inside, each Instance runs its own life: the Runtime starts the root and hands it every Message. See ADRs 0025 and 0026. The `Definition` type is now `ActorDefinition`, and `Handled` gives the `commands` an Update asked for instead of a `change`. The Frame is removed: Views no longer get `frame`, `useRuntime()` no longer returns it, and `motion` is no longer a peer dependency. What changes over time arrives as Messages.
