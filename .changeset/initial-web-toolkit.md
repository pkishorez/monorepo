Initial release under the `@kstackz` scope.

The one Toolkit for web apps on TanStack Start: the Theme, sound feedback, touch and keyboard input, shadcn components and viewers, a form hook, Recipes (the Frame, Thumb Picker, Swipe Row, Local Sign-In, Account Switcher), a root document an app gets in one call, the browser as an app's platform for auth-toolkit's `createApp` (`webPlatform`), the `/rpc` server, and an optional PWA. It replaces `@kstackz/ui-toolkit` and `@kstackz/pwa-toolkit`, which were never released. You need it so every web app does not wire the same document, sign-in, server, and offline support by hand.
