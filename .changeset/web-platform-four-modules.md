The Web Platform is four modules, each one door per subpath, and every import path changes. `ui` is what is seen and touched: `ui/theme`, `ui/components/*`, `ui/viewers/*`, `ui/form` and `ui/input`, which now holds the key bindings and sounds. `pwa` is the PWA: `pwa` (the page's side, with the extras and splash screens), `pwa/vite`, `pwa/worker` and `pwa/rpc/*`; `pwa/client`, `pwa/extras` and `pwa/splash` are gone. `recipes/*` are whole features: the Account Switcher moves here, Kabuki's devtools and their dock are one `recipes/devtools`, and `gate-screens` and `account-lost` are deleted. `app` puts an app together:

- `app/vite`: `app({ name, platform, app, loaders })` is every Vite plugin an app needs, Tailwind, React, Kabuki Start and the PWA, with the Web Platform bundled for the server; `pwa: false` makes the app no PWA (`noPwa()` from `pwa/vite`).
- `app/document`: `document({ theme, head, around })` is the Document to pass to `Start.app`, so an app writes no `document.tsx`. It includes the PWA's head and prompts whenever the build has the PWA. It replaces the `Document` component of `start`.
- `app/alchemy`: the Stage rules (`prod`, `demo`, `prN` reach the world only with `ALLOW_DEPLOY=true`), `where` an app's Workers are served on the Stage, `Site`, a Kabuki Start app as a Cloudflare Website on its domain, and `State`, opt-in, Cloudflare's state store for a deployed Stage and the disk for anyone's own. It replaces `server`.

The PWA works out how each page works offline from its Render Mode, from Kabuki Start's Pages: on install the worker saves the App Shell and every static page that is one URL; a client page is answered with the App Shell, a static one with its saved copy, a dynamic one from the network and then its last copy, and anything else offline with the App Shell. The Offline Fallback page, `navigation.shell`, `shellPath`, `offlineFallback` and `cachePages` are gone. `pwa()` needs only `name`: the manifest's colors are the default Theme's and its icons are the ones `public/` holds by name, and the Install Prompt is titled with the name, so `Pwa` takes no `installTitle`. `createTheme().manifest()` is gone.
