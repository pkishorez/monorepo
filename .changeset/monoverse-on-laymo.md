Monoverse draws a monorepo the way Laymos draws a Project. Packages sit in boxes for their folders (`apps`, `toolkits`, …), ranked by their dependencies, or all together in one stack with the Ranks layout. Changed, added, and deleted Packages are marked, and a badge shows which Packages have a Laymos Config and which have Stories. Right-click a Package for its files, README first, or the empty canvas for every file in the monorepo; double-click a Package to open it in Laymos.
