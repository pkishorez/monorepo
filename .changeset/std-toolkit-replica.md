`@kestack/std-toolkit/replica`: Kabuki-native sync. `Replica.make` says a Replica's Key and Collections, `Replica.build` its Gate and a Strategy per Collection (`oldToNew`, `newToOld`). Each Key is an Instance, an actor that shows what the Store holds in plain `@tanstack/db` Collections and fetches only while it leads and its Gate is open. A page Provides `Replicas.layer({ linger })` and places `Replicas.child([...])` once; `Pocket.get(key)` holds an Instance from a Query, an Action or a Worker, and `Replicas` shows every running one as `state`. `Query.make` is an actor whose Model is rows from any Instances, one Message per change. `Action.make` is a Command that makes Optimistic Changes with `Action.optimistic`, Confirms what the Backend returned with `instance.confirm`, and rolls every change back if anything fails. The Store is `Store.idb()` from `./replica/idb`, shared by tabs through Web Locks and a BroadcastChannel, or `Store.memory()` from `./replica/memory`; `Store.remove` stops an Instance everywhere before deleting it, and `retired` deletes old Replicas as it starts. `@kestack/kabuki` and `@tanstack/db` are new optional peers.
