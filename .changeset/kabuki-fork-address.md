A Fork, or any start of the Runtime again on a History its Router already wrote the address from, carries on at the Step's own page: the Router puts the address back on that entry, going to it in the browser's history when it kept one, instead of following the address the tab was left on. Time Travel still leaves the address as it is. `Start.app` takes `name`, what the app is called in the browser and the name its History and Window are kept under; without one, every Start app is called `Router`, its root Actor.
