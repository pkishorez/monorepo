`@kestack/connect/browser`: a computer whose code Plugin comes to run another Release (the Computers fake's Run another release, and back) drops every socket it held, as `ke-connect` swapping the Plugin does, so Code sees the mismatch at once rather than on its next reconnect. A computer that stops or restarts drops its sockets before its code Plugin stops, as a process that goes away does, so no stream is told it ended and Code's watches (Speech to Text, the Replicas) carry on once it is back.
