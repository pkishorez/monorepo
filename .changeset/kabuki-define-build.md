An Actor is written in two steps that can live apart: `Actor.define(name, { input, props, model, state, message, requires })` says what it is, and `Actor.build(Definition, { init, on, state, children, workers, provides })` how it behaves; `Actor.make(…).build(…)` is gone. A page is the same: `Page.define({ path, params, query, data, render, metadata, pages, model, state, message, requires })` names the definitions of the pages under it, and `Page.build(Definition, { pages, … })` the build of each; `Route.page` is gone. A page is drawn with `View.make`, as any Actor is: `Route.view` is gone, and so is the Place written around each page, so `self.children.X` is the page itself. The Router holds the data of every page on screen and hands each its own as `status`, and every page Requires `Navigation` without saying so. The router is defined from the root page's definition with `Router.define(App, { redirect, notFound, base, delay, preload, preloadDelay, …scroll restoration })`, which imports no build, so a page's build moves the app with `Router.push(router.X())`: the function form of a move is gone. The root page's own `metadata` replaces the tree's. `Router.app(router, AppView)` and `Start.app(router, AppView, { document, layer })` take the router and the View of the root page's build. `Route.notFound()` and `Route.redirect()` are `Page.notFound()` and `Page.redirect()`; `usePending()` is `useRouter().pending`. `View.lazy(Actor, () => import(…))` takes the Actor it draws, so the router preloads a page's code by its build. Every View carries the Actor it draws, and a new Instance in the same place is drawn with fresh React state.
