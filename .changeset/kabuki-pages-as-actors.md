A page is an Actor with a place in the URL: `Route.page({ path, params, query, data, render, metadata, pages, model, state, message, requires }).build(…)`, drawn with `Route.view(Page, …)`, and the Routes are read down from the root page with `Route.tree(() => App)`. Kabuki writes a Place around each page that loads its data and hands it in as `status`, `Loading`, `Failed` or `Ready { data, refreshing }`; a page takes no Input and draws all three itself. Child pages are the page's Children, a page with pages is a place on its own when the URL ends at it, and a parent and its page load side by side. `Route.path`, outlets, pending and failed screens, `Routes.X.props` and `Router.app`'s `failed` and `pending` options are gone. The Router holds a move up to 150ms, then lands with each new page loading. `Router.cached` adds the Data cache, which Start's browser uses: Back, a link to a page seen before and a preload show its copy at once. `Router.Link` preloads on hover, once in view, or never; `Router.preload`, `Router.reload` and `Router.Retry` are new. A move takes a Route or a function that makes one, `Router.push(() => Routes.X())`, so a page's Update can use the Routes it is part of. A single Child can name a `key`, and is made again when it changes. The Loader RPC answers each place on its own line as its Loader is done, and Start draws a page whose Loader broke or found nothing failed, with a `500` or `404`, and a client page loading.
