On a device with no keyboard every Picker opens in the Picker Mode its opener chose, whatever the width: Session Actions, the Microphone Picker and the model's settings in a Drawer from the bottom; the Project Picker and its folders, the model from the agent or model, the Session Switcher and Skills in a Dialog at the top. Each Step is named in a header with a back button, a setting's choices show no search, a folder is opened with "Open this folder", and a tap outside the Dialog with its search focused only puts the keyboard away. With a keyboard, Pickers are as before, though a long row label now ends in an ellipsis.
