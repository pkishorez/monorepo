Three Pickers open from anywhere, even while typing. `Ctrl+P` opens the Project Picker: recent projects, most recently active first, then "Open folder…", which walks the folders under home one Step each (Enter or `Ctrl+L` in, `Ctrl+H` out, a typed `~/code/fo` goes to `~/code` and searches `fo`, hidden folders only for a search starting with `.`), chooses one with `Mod+Enter`, or creates one with a git repository; choosing a project starts a new session in it, composer focused. It replaces the add-a-folder form on the home page and in the sidebar. `Ctrl+J` opens the Session Switcher across projects, Settled sessions last and quieter. `Ctrl+K` opens Session Actions, replacing the header's session menu: Settle or Un-settle, Fork from the latest turn, Go to the original, Regenerate the title, Stop the turn. `Ctrl+N` starts a new session in the project open, `Ctrl+B` shows or hides the sidebar, and `Ctrl+,` goes to Settings and, again or by Escape, back. `/p/:id` is now a new session in the project and no longer lists its sessions. Titles and hints name keys as the user bound them, the composer hands app keys to the page before macOS's text-editing Ctrl keys, the shortcut recorder refuses a key that would type for an Action that works while typing, and a Picker opened over another keeps the keyboard when the old one goes. `Ctrl+P` works while the sidebar shows the Settled List. Choosing a project or a session, or going to a fork or the original from Session Actions, takes the keyboard to the page, composer focused, even when the Picker was opened from the sidebar. `Ctrl+H` and `Ctrl+L` go to the sidebar and the page with Vim Mode off and while typing; `Space e` stays a Vim Mode key of its own. The remove-project confirmation and the Background Jobs popover put focus back where it was however they close.
