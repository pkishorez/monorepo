The app is on every Machine at once. It holds an `Ai` Instance for each Machine in the Machine List, each syncing over its own Machine's socket: a Machine added opens one, and one forgotten leaves the list, lets go of it, and has its database deleted. The Machine Switcher is gone, and so is the Machine each Account was last on. Home, the sidebar, the Pickers, Background Jobs and Settings are at the root, `/` and `/settings`; only a project and a session, `/m/:machineId/p/:projectId[/s/:sessionId]`, name their Machine. The sidebar is one list of every Machine's projects, each with its Machine's name in small text while there is more than one, and, while that Machine does not answer, when it was last seen; what it synced stays readable. The Project Picker's first Step picks the Machine, skipped with only one; the Session Switcher lists every Machine's sessions and Session Actions run on the open session's Machine. Settings lists the Machines from the Backend at once, each in its own section with its Harness Binaries read from the Machine itself, saying so when it does not answer. Screens draw what this device holds at once, a quiet skeleton only for what it has never synced, and no spinner while the Machines are found.
