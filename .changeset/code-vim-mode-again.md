Vim Mode is a choice again, off until turned on, by Mod+Alt+V or the switch in Settings, and kept in this browser. Off, the app is worked as any other: the Draft is a text box, Enter sends, plain keys type, and Ctrl+P, Ctrl+J, Ctrl+K, Ctrl+N and Ctrl+B open the Project Picker, the Session Switcher, Session Actions, a new session and the sidebar, as every other Ctrl key does. On, the keyboard is as it was, the app floats as a window with the keys' status line at its foot, and dialogs and Pickers open at once. An empty Draft shows its cursor at its start, its placeholder drawn behind the editor rather than in its text, and the placeholders say less: "Reply to the agent", "Steer the agent while it works", "What should the agent do?". Settings and the keys sheet list the keys by what they do, one row per thing, with its keys in either Mode beside its Vim Mode ones; Ctrl+/ shows the keys in either Mode. In Vim Mode, `t` switches the theme.
