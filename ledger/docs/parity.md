# Parity: Ledger web and Ledger on Expo

The Phase 5 audit of `plan.md`'s bar, "the same level of cadence for the
Expo app as for the web": every web feature has a native counterpart, or a
written reason why not. It replaces the earlier checklist
(`.claude/specs/ledger-on-expo.parity.md`), whose one-line behaviours are
folded in here. Words follow `ledger/CONTEXT.md`. Audited at `29c5d525`
(branch `ledger-on-expo`), by reading code, `ledger/NOTES.md` (Phases 3a to
4b) and the screenshots in `ledger/expo/docs/screens/`; nothing was run.

Out of scope by decision, so not counted as gaps: Keys on native (and with
them the palette, key hints, the Leader and key Sequences), Expo for web,
store release (EAS, Universal Links, icons, `expo-updates`), and web's move to
per-User tokens.

**Paths.** `web/` is `ledger/web/src/client/screens/`, `expo/` is
`ledger/expo/src/screens/`, `etk/` is `toolkits/expo-toolkit/src/`, `core/`
is `ledger/core/src/`. Other paths are from the repo root.

**Status.** `same`: a User sees and does the same thing. `differs`: there is
a native counterpart that looks or behaves otherwise. `missing`: native has
nothing. **Accepted** in the Fix column means: record it, do not fix it, for
the reason given (listed again at the end).

**Fix.** Size S (under an hour), M (half a day), L (a day or more); owner
package; batch (A, B or C, below).

   is installed and updates with a build; `expo-updates` waits for store
   release.
3. **Wide layouts** (two columns, "Open an entry", Add as a centred card):
   phones only for now; batch B turns off `supportsTablet` meanwhile.
4. **The Sidebar opens from the left edge only**, not from anywhere: the
   glossary gives the edge to the Sidebar; a right swipe anywhere would fight
   the sideways pill rows and the new Section swipe inside one
   `GestureSurface`. It does follow the finger once batch A lands.
5. **No iOS back swipe**: the left edge is the Sidebar's (glossary); Android's
   back button gets Jump instead (batch B).
6. **Status bar colour does not follow the Sidebar**: the bar is transparent
   over whatever is under it.
7. **Nothing marked on Entries or Months until Jump or Next**: with no keys
   an always-marked first row would only look selected.
8. **Day stepper instead of a date field** (Entry and Add): no date-picker
   dependency; revisit if Users pick far days.
9. **Currency as pills, a taller memo field**: five short choices; cosmetic.
10. **User Switcher as an inline list**, not a dropdown: no popover in the
    toolkit, and inside the drawer it is easier to reach.
11. **Remote sign-in in the system sheet with iOS's alert first**: ADR 0009.
12. **Add sheet slides up** rather than opening in place: the native sheet
    tracks the keyboard, so the focused amount lands in view anyway.
13. **Gesture Haptics differ from web's vibrations**: on purpose (glossary).
14. **Expo Go's white loading screen**: a development build shows the dark
    splash.
15. **iOS lists bounce**: the platform's own scrolling.
16. **One failed poll after a token expires**: the next poll succeeds; whether
    a Session should ask for a fresh token itself is an open question in core
    (NOTES 4b).
17. **Sign out everyone has no "other apps" line**: the phone's sign-in sheet
    keeps its own cookies, so other apps are not signed out.
