The board has lived in memory for twenty-three chapters, everything in it vanishes when the process ends, and it is time to keep the tasks somewhere real. This chapter takes the save-then-read program from chapter 4, exactly as written, and runs it on SQLite, on IndexedDB and on DynamoDB. Nothing about the program changes except the line that says which database to use; each database is set up once before the first write, and all four give back the same task.
