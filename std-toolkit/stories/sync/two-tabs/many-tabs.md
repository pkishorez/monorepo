# Many tabs

A second tab opens. Where does its data come from?

It comes from the backend. It does not come from the first tab. Each tab holds
its own copy. A new tab starts empty. The same worker that filled the first tab
fills the new one.

Peer sync also exists. The second Story says what it is. It is a speed path
between tabs that are already open. It carries confirmed entities sideways so
that the tabs agree sooner. It is not a source of truth. It cannot replace
startup.
