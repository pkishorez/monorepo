# Many tabs

A second tab opens. Where does what it shows come from?

From the backend — not from its sibling. Each tab owns its own replica, and a
new one starts empty and is filled by the same worker that filled the first.

Peer sync exists, and the second Story here is about what it _is_: a freshness
path between tabs that are already live, carrying confirmed entities sideways so
they converge sooner. It is never a source of truth and never a substitute for
startup.
