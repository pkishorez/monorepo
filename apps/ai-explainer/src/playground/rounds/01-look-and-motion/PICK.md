**Picked:** One canvas

**Rejected:** Keynote, Living interface

**Why:** I really like the canvas structure because it moves the story from one place to the other in a nice manner. Also the camera transitions look very consistent and improving any sort of animation in there is going to be much simpler to reason about. All the explainer videos is going to have one big canvas where we start with the first step and then walk through each one and then zooming out it's going to be very clear to the user what is going on Transitions are also smooth actually the voiceover itself is kind of a bit slow I would say but other than that it is pretty good
