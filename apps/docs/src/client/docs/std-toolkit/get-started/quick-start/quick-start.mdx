You've seen the big picture. Now build the smallest real thing: a task
list that saves, renames and deletes tasks, then learns a new field
without losing a single saved task. Four steps, and no database to set up.

## Install

std-toolkit is built on [Effect](https://effect.website), so you add both:

```sh
pnpm add @kestack/std-toolkit effect
```

## 1. Describe a task

A task has a board and a title. You write that once, as an
**EntityESchema**: a name, the field that holds its id, and its fields.

```ts file=./components/task.ts

```

This is the description everything else reads from. Every save is checked
against it, and every read hands you a value typed by it.

## 2. Give it a table

A task needs somewhere to live. You make a table, then bind `Task` to it
and say which field groups tasks together.

```ts file=./components/table.ts

```

That binding, `task`, is an **entity**: a shape with a key and a place to
live. Tasks on the same board sit together, so listing a board is one
query. The [Entities](/std-toolkit/what-is-an-entity) Part explains every
piece.

## 3. Save and read

`task` has the calls a list needs: `insert`, `get`, `query`,
`getAndUpdate` and `delete`. Each is an Effect that runs against a table.
Here, the table is kept in memory.

<Callout title="Remember">
  A shape, a table, and the shape bound to the table. Change the shape by adding
  a version, and every task already saved reads in the new one.
</Callout>
