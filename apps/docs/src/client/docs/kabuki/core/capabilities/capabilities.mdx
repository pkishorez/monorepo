We left the Song with a wish: it wants to say "play me". The Song could
Emit it to its parent, as on the Children page. But what plays the music
might live much higher up, with many levels in between, and each level
would have to pass the word on. The Song shouldn't care where the player
is.

In React, you'd solve this with context: a provider up the tree, and any
component below can use what it offers. kabuki has the same idea, called
**Capabilities**.

## Provide it above, use it below

A parent **Provides** a Capability. Anything below it, its Children, their
Children and so on, can use it. The Song doesn't ask "who is my parent?".
It just asks for a Player, and the nearest Actor that provides one
answers.

Look at how the answer comes back. The Playlist doesn't reach into the
Song. Its Model changes, and the new Props flow down like before. Data
still flows one way.

## What it looks like

A Capability is an Effect service: a name, and the functions it offers.

```ts
export class Player extends Context.Service<
  Player,
  { readonly play: (id: string) => Effect.Effect<void> }
>()('docs/Player') {}
```

The Playlist provides it. Here, `play` sends the Playlist a Message, so
asking for a song is just one more Message, kept like any other.

```ts
provides: (self) =>
  Layer.succeed(Player, {
    play: (id) => self.send({ _tag: 'Played', id }),
  }),
```

The Song says it **Requires** a Player, in its Definition. Then a Command
can use it:

```ts
requires: [Player],
```

```ts
const play = Command.make('play', {
  args: Schema.Struct({ id: Schema.String }),
  run: ({ id }) =>
    Effect.gen(function* () {
      const player = yield* Player;
      yield* player.play(id);
    }),
});
```

Requires are checked by TypeScript. Use a Capability you didn't list, and
it doesn't compile. Put a Song somewhere nothing provides a Player, and
that doesn't compile either.

## For the outside world, too

Not everything comes from an Actor. An API client, a clock, storage: these
come from outside the tree. You hand them to the whole app as a Layer, the
`layer` of `View.app`. Any need that no Actor provides is covered
there.

Here the same Song sits on a Shelf that provides nothing. Its need for a
Player climbs to the root, so `Runtime.start` must be given a Layer with
one.
