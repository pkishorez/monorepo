You will build a counter: one Actor, drawn by React. It takes three files
and about forty lines.

## Install

kabuki runs on [Effect](https://effect.website) and draws with React.

```sh
pnpm add @kestack/kabuki effect react
```

## Define the Actor

An Actor is written in two parts. `Actor.define` says what it holds and which
Messages it takes, as Schemas. `Counter.build` says what each Message does to
it: an Update gets the Message and the current Model, and returns the next
one.

```ts file=./components/counter.ts

```

Updates are plain functions with no side effects, so this file is easy to
test and to read.

## Draw it

`View.make` draws the Actor with React. It gets the Model and `send`, and
nothing else: it cannot change the Model itself, only send a Message.
`View.app` turns the View into a component that runs the app.

```tsx file=./components/counter-app.tsx

```

`View.app` also takes a `layer`: what the app's Actors need from the outside
world, such as an API client. The counter needs nothing, so it gives none.

## Use it

`CounterApp` is a plain React component. Put it anywhere.

```tsx
import { CounterApp } from './counter-app.tsx';

export function Page() {
  return <CounterApp />;
}
```

## Next steps

You just made an Actor and drew it with a View. Everything else in kabuki
builds on those two. Read the story from the start with
[Actor](/kabuki/actor), the first page of core.

Your app grows a part at a time. Add routing to give it
[pages](/kabuki/pages), each with a place in the URL. Then add start to
[serve it](/kabuki/serving) as one app. To begin a whole app, copy
[apps/kabuki-start](https://github.com/pkishorez/monorepo/tree/main/apps/kabuki-start):
the smallest Kabuki Start app.
