# docs

The site that teaches every kestack package, one package at a time, in the
order its ideas are read.

## Language

**Part**:
One section of a package's docs, named and pathed as the piece of the package it teaches, and read in order: each Part uses only the ones before it.
_Avoid_: chapter (that is the home page's word), module, topic

**Picture**:
A small animated drawing of one idea, looping through still steps, that a page shows early.
_Avoid_: video, animation, illustration, diagram

**Live Table**:
A real std-toolkit table on the Memory adapter that the reader drives with buttons on one page, showing the rows as stored beside the values as read. It keeps nothing: it starts empty on every visit.
_Avoid_: playground, sandbox, demo database, IndexedDB demo

**Shelf**:
Where a package sits in ke stack, for the sidebar's switcher: a library to build with, such as kabuki or std-toolkit, or an app.
_Avoid_: category, section (that is a sidebar heading), group (that is a few pages under a small title)
