# Only the User and Connect's own agents reach a Computer, for now

A Computer is reached only by the User it belongs to, signed in; there is no
sharing, and no device is paired or approved on its own. A Plugin's MCP is
called only by agents Connect itself runs, such as KE Code's and KE Bot's,
never by an agent outside Connect such as claude.ai. Both are deliberate
"not yet"s that keep one simple trust rule while Connect v2 is built: sharing
a Computer, and letting outside agents in, are each a later decision with
their own sign-in.
