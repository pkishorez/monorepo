# STD toolkit

Three parts, each usable on its own:

- **Modeling** — evolving schemas, entities, and STD tables. Read [the modeling guide](modeling/guide.md).
- **API surface** — server operations and their public contracts. Guidance is pending.
- **Sync** — keeping client and server data in sync. Guidance is pending.

Start with the requested part. A complete setup starts with modeling.
For API surface or sync, clarify the requested work using the project’s existing code; these sections will be designed separately.
